AdBonk — Bonk Twitch ads.

The stable userscript and both browser extensions now share version **1.0.7**. This release makes installation easier to follow and improves small icons while preserving the blocking runtime from v1.0.1.

## Downloads

| File | Version | Status |
| --- | --- | --- |
| `vaft.user.js` | 1.0.7 | Stable userscript |
| `adbonk-chromium-1.0.7.zip` | 1.0.7 | Stable Chromium extension for local installation |
| `adbonk-firefox-1.0.7.zip` | 1.0.7 | Stable Firefox extension; unsigned ZIP for temporary installation |

Both extensions bundle the stable userscript byte-for-byte. The MIT license is also attached.

## Changes

- Unified versioning across userscript and extensions. The shared sequence starts at 1.0.7 to stay above earlier extension builds, which used independent versions. Future stable releases use the same number for every installation format.
- Added userscript icon metadata so compatible managers can display AdBonk's mascot.
- Simplified the 16px and 32px toolbar icons to a transparent mascot face with fewer details. The existing banner and larger mascot-and-mallet icons are unchanged.
- Reorganized the README with direct userscript and Firefox installation links, short steps for each setup, and expandable details for updates, migration, and local installation.

The blocking runtime and internal conflict counter are unchanged from v1.0.1. Experimental and legacy userscript variants remain separate.

## Install or update

- **Userscript:** [install AdBonk](https://raw.githubusercontent.com/rafelolv/AdBonk/main/vaft/vaft.user.js) with Tampermonkey or Violentmonkey, or check for updates in your manager. That link follows `main`; the attached file is this release's snapshot. Existing AdBonk 1.x installations can update normally.
- **Chrome, Brave, and Edge:** use the userscript for the standard setup. For the standalone extension, extract the Chromium ZIP, enable Developer mode on the extensions page, and select Load unpacked. To update an existing local installation, replace its files and reload the extension. There is no Chrome Web Store listing.
- **Firefox:** use [Mozilla Add-ons](https://addons.mozilla.org/en-US/firefox/addon/adbonk/) for regular installation. Store updates require separate submission and review, so its version may lag behind this release. The attached GitHub ZIP is unsigned: extract it and load `manifest.json` through `about:debugging` → This Firefox → Load Temporary Add-on. Temporary installation is removed when Firefox restarts.

Use one installation method at a time and reload Twitch after updating. GitHub does not automatically update unpacked or store extensions. See the [setup guide for this release](https://github.com/rafelolv/AdBonk/blob/v1.0.7/docs/EXTENSION.md).

## Validation and known limitations

All 148 automated tests pass, including checks that both manifests, bundled userscript metadata, and build-info fields use the shared version. A deliberately mismatched version was rejected before packaging. Archive integrity, transparent icons, and equality of the bundled core were verified.

Chrome and Firefox fixture checks passed for extension installation, injection, status, duplicate detection, and the popup. The README was checked in local wide and narrow previews. The new userscript icon metadata has not been tested inside a real userscript manager; live Twitch ad delivery was not retested for this visual and packaging update. Browser fixtures do not reproduce real ad delivery.

[Report a problem](https://github.com/rafelolv/AdBonk/issues) with your browser, installation method, version, and what happened. Fixes and pull requests are welcome.
