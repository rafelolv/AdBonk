## Install or update

- **Userscript:** [install AdBonk](https://raw.githubusercontent.com/rafelolv/AdBonk/main/vaft/vaft.user.js) with Tampermonkey or Violentmonkey, or check for updates in your manager. That link follows `main`; the attached file is this release's snapshot.
- **Chrome, Brave, and Edge:** use the userscript for the standard setup. For the standalone extension, extract the Chromium ZIP, enable Developer mode on the extensions page, and select Load unpacked. To update an existing local installation, replace its files and reload the extension.
- **Firefox:** use [Mozilla Add-ons](https://addons.mozilla.org/en-US/firefox/addon/adbonk/) for regular installation. Store updates require separate submission and review. For temporary local installation, extract the unsigned Firefox ZIP and load `manifest.json` through `about:debugging` → This Firefox → Load Temporary Add-on. Temporary installation is removed when Firefox restarts.

Use one installation method at a time and reload Twitch after updating. GitHub does not automatically update store or unpacked extensions. See the [setup guide](https://github.com/rafelolv/AdBonk/blob/v1.0.8/docs/EXTENSION.md).
