AdBonk — Bonk Twitch ads.

This release adds automatic Firefox Add-ons submission after GitHub publication. The userscript and both extensions share version 1.0.9; ad-blocking behavior is unchanged.

## Downloads

| File | Version | Status |
| --- | --- | --- |
| `vaft.user.js` | 1.0.9 | Stable userscript |
| `adbonk-chromium-1.0.9.zip` | 1.0.9 | Stable Chromium extension for local installation |
| `adbonk-firefox-1.0.9.zip` | 1.0.9 | Stable Firefox extension; unsigned ZIP for temporary installation |

Both extensions bundle the stable userscript byte-for-byte. The MIT license is attached.

## Changes

- GitHub Actions submits the Firefox package to the existing Mozilla listing after a successful tagged release, when repository credentials are configured.
- The published Firefox ZIP must match the reproducible tagged build before submission. Six new tests cover publication guards.
- Added setup and recovery instructions for Firefox publishing. Credentials stay in GitHub Actions secrets.

## Install or update

- **Userscript:** [install AdBonk](https://raw.githubusercontent.com/rafelolv/AdBonk/main/vaft/vaft.user.js) with Tampermonkey or Violentmonkey, or check for updates in your manager. That link follows `main`; the attached file is this release's snapshot.
- **Chrome, Brave, and Edge:** use the userscript for the standard setup. For the standalone extension, extract the Chromium ZIP, enable Developer mode on the extensions page, and select Load unpacked. To update an existing local installation, replace its files and reload the extension.
- **Firefox:** use [Mozilla Add-ons](https://addons.mozilla.org/en-US/firefox/addon/adbonk/) for regular installation. This release triggers automatic submission when repository secrets are configured. Availability still depends on Mozilla review. For temporary local installation, extract the unsigned Firefox ZIP and load `manifest.json` through `about:debugging` → This Firefox → Load Temporary Add-on. Temporary installation is removed when Firefox restarts.

Use one installation method at a time and reload Twitch after updating. GitHub does not automatically update store or unpacked extensions. See the [setup guide](https://github.com/rafelolv/AdBonk/blob/v1.0.9/docs/EXTENSION.md).

## Validation

All 154 automated tests pass, including package consistency and publication guards. Both extension packages were rebuilt and verified. The stable userscript runtime and internal conflict counter are unchanged; only its public version metadata advances. Live Twitch playback and browser integration were not retested because blocking and integration code are unchanged. Automatic submission does not establish Mozilla approval.
