AdBonk — Bonk Twitch ads.

Restores the original blocking strategy and player focus/recovery routines after reports of better playback with that baseline. Userscript and extensions share version 1.0.13.

## Changes

- Restored original ad detection, backup selection, quality matching, and ad-end reload behavior. Normal backup order is embed, popout, then autoplay (360p); briefly after reload, autoplay can be tried directly.
- Removed added acceleration, backup pinning, synthetic recovery, and extra reload heuristics. Focus and recovery also use the original routines, without the additional VOD/video-target/route or PiP guards.
- Preserved AdBonk identity, frame/clip exclusions, bounded network transport, and shared extension packaging. Experimental and legacy variants are unchanged.
- Firefox submission notes now respect Mozilla's 3,000-character limit.

## Install or update

- **Userscript:** [install or update AdBonk](https://raw.githubusercontent.com/rafelolv/AdBonk/main/vaft/vaft.user.js) in your manager. This link follows main; the attachment is the release snapshot.
- **Chrome, Brave, Edge:** extract the Chromium ZIP and load its folder using Developer mode → Load unpacked. Replace files and reload an existing local installation to update.
- **Firefox:** use [Mozilla Add-ons](https://addons.mozilla.org/en-US/firefox/addon/adbonk/). This release triggers submission; availability depends on Mozilla. For temporary testing, extract the ZIP and load manifest.json through about:debugging. Temporary installation ends when Firefox restarts.

Use one blocker at a time and reload Twitch. Local extensions require manual updates. [Setup and limitations](https://github.com/rafelolv/AdBonk/blob/v1.0.13/docs/EXTENSION.md).

## Validation and limits

All 89 current tests pass, including pinned function equality and generated-worker execution. Chromium/Firefox fixture checks passed for this runtime. Mozilla lint found zero errors and one existing Android compatibility warning; Android support is unverified.

Live Twitch ad breaks, native PiP, and third-party extension interactions were not tested by the agent. The original strategy can still buffer or lower quality; this is not a guarantee of better results in every session.
