AdBonk — Bonk Twitch ads.

This release fixes recovery actions targeting the wrong video and temporary playback acceleration remaining on a previous video. The userscript and both extensions share version 1.0.11.

| File | Version | Status |

| `adbonk-firefox-1.0.11.zip` | 1.0.11 | Stable Firefox extension; unsigned ZIP for temporary installation |

Both extensions bundle the stable userscript byte-for-byte. The MIT license is attached.

## Changes

- Recovery targets the live player's video instead of selecting a side/chat ad video by page order. Pending reload actions stop applying after channel or player-state changes, VOD navigation, or a deliberate pause. Unrelated video events cannot trigger audio restoration. Fixes [#1](https://github.com/rafelolv/AdBonk/issues/1).
- Temporary catch-up playback restores the previous speed on the video it accelerated when recovery completes, stops, fails, or is replaced. Old callbacks cannot interrupt a newer correction, and external speed changes are preserved. Fixes [#2](https://github.com/rafelolv/AdBonk/issues/2).
- Userscript names and stable diagnostic labels use AdBonk. Installation and update URLs are preserved.

Playlist processing, backup selection, and quality priorities are unchanged. A lower-quality fallback may still be used during ads when higher-quality alternatives are unavailable.

## Install or update

- **Userscript:** [install AdBonk](https://raw.githubusercontent.com/rafelolv/AdBonk/main/vaft/vaft.user.js) with Tampermonkey or Violentmonkey, or check for updates in your manager. That link follows `main`; the attached file is this release's snapshot.
- **Chrome, Brave, and Edge:** use the userscript for the standard setup. For the standalone extension, extract the Chromium ZIP, enable Developer mode on the extensions page, and select Load unpacked. To update an existing local installation, replace its files and reload the extension.
- **Firefox:** use [Mozilla Add-ons](https://addons.mozilla.org/en-US/firefox/addon/adbonk/) for regular installation. This release triggers automatic submission when repository secrets are configured. Availability still depends on Mozilla review. For temporary local installation, extract the unsigned Firefox ZIP and load `manifest.json` through `about:debugging` → This Firefox → Load Temporary Add-on. Temporary installation is removed when Firefox restarts.

Use one installation method at a time and reload Twitch after updating. GitHub does not automatically update store or unpacked extensions. See the [setup guide](https://github.com/rafelolv/AdBonk/blob/v1.0.11/docs/EXTENSION.md).

## Validation

All 176 automated tests pass, including 22 new recovery regression cases. Against the previous stable implementation, 21 of those 22 cases fail. Chromium and Firefox extension fixture checks passed for the same runtime, and both release packages were rebuilt and verified against the stable userscript. All 17 serialized worker functions match the previous implementation.

The maintainer reports that stream quality returns to normal after ads. Live Twitch recovery scenarios, native Firefox PiP, and third-party extension interactions have not been exhaustively verified. These scoped fixes do not establish that every freeze or pause is resolved. Mozilla submission and approval are separate steps.

[Report a problem](https://github.com/rafelolv/AdBonk/issues) with your browser, installation method, version, and what happened.
