AdBonk — Bonk Twitch ads.

The first AdBonk release brings together the maintained stable userscript and optional experimental browser extensions. It continues pixeltris's TwitchAdSolutions with updates from ryanbr's fork. Thanks to both projects and their contributors; the original history and MIT license are preserved.

## Downloads

| File | Version | Status |
| --- | --- | --- |
| `vaft.user.js` | 1.0.0 | Stable userscript; recommended installation |
| `adbonk-chromium-1.0.1.zip` | 1.0.1 | Experimental extension for Chrome and other Chromium browsers |
| `adbonk-firefox-1.0.1.zip` | 1.0.1 | Experimental, unsigned Firefox extension for temporary installation |

The extension versions are independent of the userscript version. Both extensions bundle the stable userscript byte-for-byte; there is no separate blocking implementation.

## Install

- **Userscript:** install Tampermonkey or Violentmonkey, then [install AdBonk](https://raw.githubusercontent.com/rafelolv/AdBonk/main/vaft/vaft.user.js). The main-branch installation receives future updates through your manager. The attached `vaft.user.js` provides this release's snapshot.
- **Chrome / Brave / Edge:** extract the Chromium ZIP, open your browser's extensions page, enable Developer mode, and choose **Load unpacked**. Select the folder containing `manifest.json`.
- **Firefox:** extract the Firefox ZIP, open `about:debugging`, choose **This Firefox**, then **Load Temporary Add-on** and select `manifest.json`. This unsigned build is removed when Firefox restarts; persistent installation requires a Mozilla-signed package.

Use one installation method at a time. Disable duplicate Twitch ad blockers and reload Twitch after installing. See the [extension guide for this release](https://github.com/rafelolv/AdBonk/blob/v1.0.0/docs/EXTENSION.md) for setup and updates. GitHub packages do not install or update through browser stores automatically.

**Migrating from earlier builds:** AdBonk restarts public userscript versioning at 1.0.0. If your installed version has a higher inherited version number, reinstall once from the current installation link; automatic update checks will not downgrade it. Internal conflict counters are preserved.

## Included changes

- Fixed live-player recovery and focus handling, including accumulating monitor timers.
- Fixed playlist-processing failures that could leave requests pending, and kept the GQL timeout active while reading response bodies.
- Simplified the player banner to “AdBonk is blocking ads.”
- Added standalone Chromium and Firefox packages with a small status popup and links to GitHub, setup, and bug reports.
- Removed the inconsistent uBlock Origin integration to focus maintenance on the userscript and its bundled extension builds.

## Validation and experimental status

The release is checked with the project's automated suites and byte-for-byte package checks. Browser fixture tests cover extension installation, injection, status, and duplicate detection; they do not reproduce real Twitch ad delivery.

The maintainer reports successful local use of the extensions in Firefox and Chrome. Detailed results for preroll/midroll ads, long viewing sessions, PiP, and other Chromium browsers have not been recorded. The extension therefore remains experimental even though the bundled userscript is stable.

Found a problem? [Open an issue](https://github.com/rafelolv/AdBonk/issues), including the installation method, browser, version, and what happened. Fixes and pull requests are welcome.
