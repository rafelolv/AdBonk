AdBonk — Bonk Twitch ads.

The browser extension is now stable following the maintainer's successful local use in Firefox and Chrome. This release includes the transparent mascot icon and a userscript update that tries higher-quality streams before repeating a 360p fallback from a previous ad break.

## Downloads

| File | Version | Installation |
| --- | --- | --- |
| `vaft.user.js` | 1.0.1 | Stable userscript; recommended for Chrome, Brave, and Edge |
| `adbonk-chromium-1.0.5.zip` | 1.0.5 | Stable extension; extract and load through Developer mode |
| `adbonk-firefox-1.0.5.zip` | 1.0.5 | Stable extension; unsigned ZIP for temporary installation |

Both extensions bundle the stable userscript byte-for-byte. Their versions advance independently. The license is included; no uBlock Origin integration is distributed.

## Changes

- Removed the Experimental label from the extension name and popup.
- Added a transparent mascot mark with a larger face and mallet for the toolbar and popup; the full illustration remains in the README.
- Disabled fast-autoplay-first by default: needing 360p for one ad break no longer makes it the first choice for the next normal backup search. The 360p fallback remains available when higher-quality alternatives have ads. Probing alternatives can add buffering time.
- Added the Firefox listing and clearer store/local installation instructions.

## Install or update

- **Userscript:** [install AdBonk](https://raw.githubusercontent.com/rafelolv/AdBonk/main/vaft/vaft.user.js) with Tampermonkey or Violentmonkey, or check for updates in your manager. That link follows `main`; the attached file is this release's snapshot.
- **Firefox:** use the [Mozilla Add-ons listing](https://addons.mozilla.org/en-US/firefox/addon/adbonk-experimental/) for regular installation. The existing URL keeps its original slug. Store updates require separate upload and review, so the listing may still show an earlier version or name. The attached GitHub ZIP is unsigned: extract it and select `manifest.json` through `about:debugging` → This Firefox → Load Temporary Add-on. Temporary installation is removed when Firefox restarts.
- **Chrome, Brave and Edge:** keep using the userscript for the standard setup. AdBonk is not on the Chrome Web Store. Google requires a [$5 one-time developer registration fee](https://developer.chrome.com/docs/webstore/register) to publish there; this is not a charge to AdBonk users. You can load the extension locally for free: extract the Chromium ZIP, enable Developer mode on the extensions page, and choose Load unpacked. To update, replace the existing local files and reload the extension.

Use one installation method at a time and reload Twitch after updating. See the [setup guide for this release](https://github.com/rafelolv/AdBonk/blob/v1.0.1/docs/EXTENSION.md). GitHub releases do not automatically update store or unpacked installations.

## Validation and known limitations

The maintainer reports that the extension works in Firefox and Chrome and has chosen to promote it to stable. Detailed results for every ad scenario and long viewing sessions have not been recorded; Brave and Edge have not been tested individually.

Automated checks cover the shipped playlist processor using simulated Twitch responses, player/network regressions, extension packaging, and equality of bundled code. Browser fixture tests cover installation, early injection, status, duplicate detection, and the popup; they do not reproduce real Twitch ad delivery or establish the quality improvement on a live stream.

All 148 automated tests and the Chrome/Firefox browser fixture checks passed for this release. Both ZIPs were checked for stable metadata, preserved Firefox identity, transparent icons, archive integrity, and equality with the stable source.

[Report a problem](https://github.com/rafelolv/AdBonk/issues) with your browser, installation method, version, and what happened. Fixes and pull requests are welcome.
