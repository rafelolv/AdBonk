AdBonk — Bonk Twitch ads.

A smaller popup with less clutter. Userscript and extensions share version 1.0.15; blocking behavior is unchanged.

## Changes

- Removed the redundant “This tab” label and the decorative yellow footer stroke.
- Tightened the layout to reduce popup height. The dark theme, mascot, help links, and author credit remain.

## Install or update

- **Userscript:** [install or update AdBonk](https://raw.githubusercontent.com/rafelolv/AdBonk/main/vaft/vaft.user.js) in your manager. This link follows main; the attached file is the release snapshot. This update only advances userscript version metadata.
- **Chrome, Brave, Edge:** extract the Chromium ZIP and load its folder using Developer mode → Load unpacked. Replace files and reload an existing local installation to update.
- **Firefox:** use [Mozilla Add-ons](https://addons.mozilla.org/en-US/firefox/addon/adbonk/). Submission is automatic; store availability depends on Mozilla. For temporary testing, extract the ZIP and load manifest.json through about:debugging. Temporary installation ends when Firefox restarts.

Use one installation method at a time and reload Twitch. Local extensions require manual updates. [Setup guide](https://github.com/rafelolv/AdBonk/blob/v1.0.15/docs/EXTENSION.md).
